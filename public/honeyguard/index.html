A small trap. A useful signal.

SOC-based Honey Document & Threat Detection System

THE IDEA

Make suspicious document activity visible.

Honey documents are decoy files placed in a repository to reveal unexpected interactions. Our project assigns each document a sensitivity level, records access, download and copy events, and turns the event context into a risk score and a security alert.

01Place a decoy

Choose a file and its sensitivity.

02Capture an interaction

Record the action, IP and device.

03Score & alert

Flag medium and high risk events.

The risk model

The exact weights used in our report.

Risk = min(100, sensitivity + activity + context)
SensitivityLow +0 · Medium +15 · High +30
ActivityAccess +10 · Download +30 · Copy +50
ContextUnknown IP +10 · Unknown device +10
SeverityLow 0–39 · Medium 40–69 · High 70–100

Example: High sensitivity + Copy = 30 + 50 = 80 / HIGH.

From report to demo

A simple way to explain the project.

The report describes a React + Vite frontend, a Flask REST API, and an SQLite database with documents, events and alerts tables.

This website is an interactive browser demo of that workflow. It uses sample metadata and local storage. It does not detect activity outside this page or connect to a Flask backend.
